    GitHub

    A fine-grained token with your own account as the resource owner. Needs read access to Metadata, Contents and Actions. Without one, only public repositories show and the rate limit is 60 requests an hour rather than 5000.

    A second fine-grained token, with your organisation as the resource owner. Two tokens are needed because a fine-grained token has exactly one resource owner — one owned by your personal account cannot see organisation repositories however its permissions are set. The alternative, a single classic token, would need the repo scope, which grants read and write on every repository you can reach; two read-only tokens are the safer arrangement.

    The organisation the work token belongs to. Strongly recommended: with it, work repositories are read straight from that organisation. Left empty, the page has to ask GitHub which organisations you belong to, which an organisation-scoped token often cannot answer — and the Work list then comes back empty.

    Comma-separated login=Name pairs, so the board shows people rather than usernames. A login with no entry is shown as itself, so nobody disappears from the list when a new colleague starts — you just see their username until you add them here.

    Calendar (Today page)

    No token to paste here: once both fields are saved, the Today page itself shows a short code and an address — open that address on your phone or computer and enter the code to finish signing in. Needs an app registration with "Allow public client flows" set to Yes and the delegated Graph permission Calendars.Read + offline_access consented; Calendars.ReadBasic is not enough, as it does not include the meeting room.

    Firmware updates

    To-dos (Telegram)

    Get a bot token from @BotFather, and your own numeric id from @userinfobot — both on Telegram. Only messages from this id are acted on; anything else is silently ignored, so a stranger who finds the bot's username cannot tell it is even listening. Message the bot to add a task, or send /list, /done <id>, /reopen <id>, /delete <id>, /clear. Typing happens in Telegram; on the device itself you can tap a task to complete it or tap its bin icon twice to delete it.
